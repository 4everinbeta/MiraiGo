## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser clarification payload→SearchService merge logic | User-controlled slot answers can tamper with existing state |
| NLP parser output→clarification decisions | Heuristic extraction influences control flow and downstream provider calls |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | T | slot merge/update handling in `SearchService` | mitigate | Restrict mergeable slot names to critical slot enum and ignore/validate unexpected keys before `model_copy`. |
| T-01-05 | D | iterative clarification turns causing repeated compute | mitigate | Exit early with single next question and skip provider fan-out until completion, limiting expensive work. |
| T-01-06 | R | user override history for constraints | mitigate | Store append-only turn history in clarification state with timestamp/slot/value transitions for auditability. |
</threat_model>
