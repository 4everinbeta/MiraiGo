| Boundary | Description |
|----------|-------------|
| user UI interactions→turn request payload | Untrusted input controls slot updates and unknown flags |
| backend warning/clarification text→rendered UI | Server-provided strings displayed in user-facing components |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | T | `web/src/app/page.tsx` payload assembly | mitigate | Build payload from typed interfaces and explicit slot keys only; avoid spreading arbitrary objects into request body. |
| T-01-08 | I | `SearchForm` rendering of warnings/questions | mitigate | Render strings as plain text nodes (no HTML injection paths) and keep fallback error copy from UI spec. |
| T-01-09 | D | repeated submit actions during turn transitions | mitigate | Keep `isSubmitting` guards on buttons and disable repeat submits while request in flight. |
</threat_model>
