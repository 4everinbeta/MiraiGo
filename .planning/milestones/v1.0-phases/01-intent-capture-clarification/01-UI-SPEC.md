## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, chip internal gaps |
| sm | 8px | Compact field/control spacing |
| md | 16px | Default element spacing, body rhythm |
| lg | 24px | Card section padding, grouped control spacing |
| xl | 32px | Major block spacing within a page section |
| 2xl | 48px | Large section breaks |
| 3xl | 64px | Page-level top/bottom breathing space |

Exceptions: icon-only interactive controls must have minimum 44px touch target.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Implementation notes:
- Body text defaults to 16/400/1.5 for prompts, helper text, and response narrative.
- Label style is required for field labels and chip captions.
- Heading is for section titles; Display is for primary phase title only.
- Maximum typography weights for this phase: 400 (regular) and 600 (semibold) only.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FFFFFF | App/page background, primary surfaces |
| Secondary (30%) | #FEE2E2 | Cards, secondary panels, recap containers |
| Accent (10%) | #2B3A67 | Primary CTA, focus ring, active/editable chips, clarification progress emphasis |
| Destructive | `var(--destructive)` | Destructive actions only |

Accent reserved for: primary CTA, keyboard focus ring, active/editable recap chips, clarification progress emphasis indicators.

---

## Visual Hierarchy & Focal Point

- Primary focal point per screen: the active clarification prompt/input area.
- Hierarchy order must be: (1) active prompt and input control, (2) primary CTA, (3) recap chips/secondary context, (4) helper/meta text.
- Enforce hierarchy using size and contrast only from this contract (Display/Heading > Body/Label; accent only on focal actions and focus states).

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Continue to Recommendations |
| Empty state heading | Start with your travel intent |
| Empty state body | Describe where, when, and budget if known. We’ll ask one follow-up at a time to fill missing details. |
| Error state | We couldn’t process that answer. Rephrase it in plain language, or set the constraint manually in the recap chips and continue. |
| Destructive confirmation | none (no destructive actions in this phase) |

Accessibility fallback for icon-only controls:
- All icon-only controls must include an accessible name (`aria-label`).
- Provide tooltip text on hover/focus.
- For critical actions, render a visible text label at `sm` breakpoint and below (icon + text), not icon-only.
