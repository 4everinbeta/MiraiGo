# Phase 07 Plan 02: Multilingual query support

## Objective

Add multilingual normalization and parsing support for common non-English intent phrasing while preserving current behavior for existing English inputs.

## Must-Have Truths

1. Supported non-English queries map into canonical intent slots.
2. Unsupported language patterns fail gracefully with lower confidence/ambiguity rather than incorrect confident extraction.
3. Existing English query behavior remains intact.

## Tasks

1. Implement lightweight language-aware normalization for frequent travel-intent tokens.
2. Extend extraction keyword pathways to map multilingual variants into existing canonical slots.
3. Add test coverage for supported multilingual queries and fallback behavior.

## Verification

## Success Criteria

- Multilingual cases parse into correct slot metadata.
- Existing English regressions remain green.
