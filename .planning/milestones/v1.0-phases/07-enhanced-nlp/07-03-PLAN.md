# Phase 07 Plan 03: Synonym expansion and robustness tuning

## Objective

Improve semantic recall for destination/activity/weather terms through controlled synonym expansion and regression-safe tuning.

## Must-Have Truths

1. Synonyms map to canonical intent values without inflating false positives.
2. Expanded synonym coverage increases successful extraction for realistic phrasing.
3. Clarification and API behavior remain stable after synonym tuning.

## Tasks

1. Add curated synonym dictionaries with precedence/guard rails.
2. Extend parser logic to apply synonym normalization before slot scoring.
3. Add targeted tests for positive/negative synonym cases.
4. Validate search API and clarification behavior with expanded synonyms.
