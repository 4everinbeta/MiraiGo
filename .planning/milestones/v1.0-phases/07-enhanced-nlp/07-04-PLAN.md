# Phase 07 Plan 04: Destination clarity for romance-language prompts

## Objective

Eliminate the "destination unclear" gap for common romance-language destination phrasing while preserving protections against English-article false positives.

## Gap Source

- 07-UAT test 1: multilingual prompt returned unclear destination.

## Tasks

1. Add a guarded destination pattern for `a <destination>` phrases only when preceded by travel-intent cues (e.g., `viaje`, `voyage`, `viagem`, `trip`).
2. Keep existing false-positive guards for English article usage (`a warm trip`) and timeline token confusion.
3. Add regression tests for:
   - positive `a lisboa`/`a lisbonne` cases with travel-intent cue,
   - negative English article phrases that must not become destinations.

## Verification

- `PYTHONPATH=. ./venv/bin/pytest src/tests/nlp/test_intent.py src/tests/nlp/test_intent_multimodal.py -q`

## Success Criteria

- Destination resolves for supported romance-language phrasing.
- Existing English and timeline safety tests remain green.
